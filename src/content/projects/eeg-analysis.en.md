## Background

Our team analyzed EEG signals using an existing dataset and developed state detection software. As a core member, I worked on method selection and software implementation.

## My role and contribution

I read relevant papers, reproduced prediction methods, tuned parameters, compared approaches, and selected an integration approach suited to the team's dataset.

## Approach and implementation

I built a PyQt5 interface for parameter configuration and visual analysis, integrating it with the prediction algorithm into a complete software application.

## Outcome

The project resulted in one software copyright registration.
