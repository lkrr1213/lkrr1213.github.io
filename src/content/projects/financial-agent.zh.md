## 背景

在北京中科金财科技股份有限公司进行 Agent 研发实习期间，我参与面向银行客户的问答 Agent 工作流和金融知识库建设。

## 我的角色与贡献

我参与意图识别、向量检索、多轮对话和合规校验等环节，完成数据清洗、文本切片、向量入库及检索策略优化，也通过提示词调整改善垂直领域问答表现。

## 方法与实现

在报告自动化工作中，我参与多源数据接入、关键信息提取、结构化内容生成和格式校验，使用 Python 输出标准化文档。

## 已有成果

参与形成问答与报告生成工作流，支持金融场景中的知识检索和文档制作。
